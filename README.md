# GAME 2D "Petualangan Mahasiswa ITBU"

Feature:
- Main Menu: Play, Info, Quit
- Attack Melee
- Obstacle : Chainsaw, Water, Quiz
- Quiz : with blood reduction if wrong
- Health 6 bar
- Mushroom add 1 health bar
- Menu
